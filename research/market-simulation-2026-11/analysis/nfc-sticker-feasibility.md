# 苔間 NFC 客製貼紙：產品與技術可行性分析

日期：2026-11-06  
範圍：iPhone 為主的 NFC 貼紙，空白貼紙綁定居民、已設定貼紙感應後開 App 並跳到該居民的快速記錄頁。

## 1. 結論先講

**NFC 貼紙可以做出來，技術風險不高；真正的風險是「需求是否足夠」與「貼紙被當成一次性贈品」。**

建議把它定位成：

1. **Pro 199 的加值配件**：3 張 299 元，或 Pro 年繳內含 3 張。
2. **爬店／繁殖者的售後工具**：10 張＋店家後台 1,999 元，這是比大眾零售更強的需求。
3. **不是獨立周邊事業**：T-shirt、托特包、徽章可以之後再做；先把「貼紙→快速記錄」的留存曲線跑出來。

技術上，iPhone XS／XR 以後的機型可背景讀取 NDEF URL；iPhone 7／8／X 需要 App 或控制中心的手動讀取；Android 與舊 iPhone 用貼紙上的 QR code fallback。**不要做 iPhone-only 的貼紙**，否則會把 Android 使用者直接排除。

## 2. iPhone NFC 能力邊界

### 可以做的

- **寫入 NDEF URL**：iOS 13 以後，App 可用 Core NFC 的 `NFCNDEFReaderSession` 連接標籤並 `writeNDEF`。需要 `NFCReaderUsageDescription`。
- **背景讀取**：iPhone XS、XS Max、XR、SE（第 2 代）與後續機型，螢幕亮著、開機後至少解鎖過一次，靠近 NDEF 標籤會出現系統通知；使用者點通知後，系統把 NDEF 交給 App 或 Safari。
- **Universal Link 開 App**：NDEF 寫入 `https://taijian.ycair.space/n/<token>`；若 App 已安裝且設定 Associated Domains，會開 App；否則開網頁 fallback。
- **App 內手動掃描**：所有支援 Core NFC 的 iPhone 都可以在 App 內主動掃描與寫入。

### 不能做的

- **不能讓空白貼紙「自己知道」要綁哪隻居民**：空白標籤沒有感應器、沒有電源，必須由 App 寫入 URL/token。
- **不能保證貼紙不可複製**：NTAG215/216 的 NDEF 是靜態資料，任何人拿到貼紙都能讀取甚至重寫。若沒有伺服器驗證，貼紙只是一張寫了網址的貼紙。
- **不能把 Apple Wallet 當成一般 NDEF 寫入**：Wallet pass 的 NFC 需要 Apple 的 entitlement 與 pass 類型，不適合這個用例。
- **不能在背景讀取所有標籤**：只有 NDEF 格式、且系統支援背景讀取時才會出現通知；金屬、厚殼、鏡頭/Apple Pay 使用中、飛航模式都可能中斷。
- **不能保證 Android 直接開 iOS App**：Android 可讀 NDEF URL，但沒有苔間 App 時只能開網頁；QR code 是最實際的跨平台 fallback。

## 3. 建議的使用者流程

### A. 空白貼紙綁定居民

1. 使用者買到 3 張一包的貼紙，貼紙上印 QR code、短碼與「NFC 感應區」。
2. 打開苔間 App →「居民」→「NFC 貼紙」→「綁定新貼紙」。
3. App 啟動 Core NFC 寫入工作階段，靠近貼紙。
4. App 向伺服器建立一個隨機 token，寫入：
   `https://taijian.ycair.space/n/<token>`
5. 使用者選擇居民、貼紙名稱（例如「球蟒 A 缸」）、權限（誰可以感應）。
6. App 回寫成功後，請使用者立刻試刷一次；成功才完成綁定。
7. 伺服器記錄 `tag_id`、`token_hash`、`resident_id`、`household_id`、`created_by`、`status`。

### B. 已設定貼紙感應

1. iPhone 靠近貼紙，系統顯示通知。
2. 使用者點通知 → Universal Link 開 App。
3. App 用 token 向伺服器解析：
   - 已登入且對該居民有權限 → 直接進「快速記錄」頁。
   - 未登入 → 登入後回到同一頁。
   - 無權限 → 顯示「此貼紙屬於另一個家庭」。
   - token 已撤銷／居民已刪除 → 顯示錯誤與重新綁定引導。
4. 快速記錄頁預設帶入居民、最近一次紀錄、常用動作（餵食、換水、體重、蛻皮、醫療）。

### C. 未安裝 App 或 Android

- 開 `https://taijian.ycair.space/n/<token>` 網頁：
  - 顯示居民暱稱、公開摘要（若允許）與「下載 App」按鈕。
  - 不顯示醫療、私人筆記或家庭成員。
- QR code 與 NFC 指向同一個 URL，避免兩套邏輯。

## 4. 技術架構

### iOS

- `CoreNFC`：
  - 掃描／寫入：`NFCNDEFReaderSession`。
  - 寫入 payload：`NFCNDEFPayload.wellKnownTypeURIPayload(url:)`。
  - 讀取：背景 `NSUserActivity.ndefMessagePayload`；App 內用手動 session。
- `Associated Domains`：`applinks:taijian.ycair.space`。
- Deep link router：`/n/:token` → 解析 → 居民快速記錄。
- 權限：`NFCReaderUsageDescription` 必須清楚說明「用來綁定與感應苔間貼紙」。
- 錯誤處理：標籤太小、寫入中斷、貼紙已鎖定、貼紙不是 NDEF、手機殼太厚。

### 伺服器

```text
POST /api/nfc/tags            建立空白 token（回傳 token + URL）
POST /api/nfc/tags/:token/bind   綁定居民（需登入與家庭權限）
POST /api/nfc/tags/:token/revoke 撤銷
GET  /api/nfc/resolve?token=...  解析 token（需登入）
GET  /n/:token                   網頁 fallback
```

資料表：

```text
nfc_tags
  id, token_hash, resident_id, household_id, label,
  status, created_by, created_at, revoked_at, last_seen_at

nfc_events
  id, tag_id, user_id, event_type, ip_hash, user_agent, created_at
```

### 安全規則

- **URL 只放隨機 token，不放 resident_id、使用者 ID、Email 或病歷**。
- token 至少 128-bit 隨機；資料庫只存 hash。
- 感應只是「開啟入口」，不是「授權」；仍要登入與家庭權限檢查。
- 撤銷要即時；貼紙遺失時，舊 token 立刻失效。
- 記錄每次感應（誰、何時、哪個 tag），用於異常偵測。
- 對外顯示的居民頁只給公開欄位；醫療與私人筆記預設不顯示。
- 若要做防拷貝，升級 NTAG 424 DNA 的 SUN/SDM；但這是第二階段，不是 MVP。

## 5. 標籤與製造

| 項目 | 建議 | 原因 |
|---|---|---|
| 晶片 | NTAG215（504 bytes）或 NTAG216（888 bytes） | URL 很短，215 已足夠；216 留給未來 signature/短碼 |
| 天線 | 標準 PVC/PET 貼紙 | 玻璃缸、塑膠盒、木櫃可用 |
| 金屬缸 | 抗金屬貼紙（含鐵氧體層） | 直接貼金屬會讀不到 |
| 防水 | PET 面材＋防水膠 | 清潔、濕氣、灑水 |
| 印刷 | 四色印刷＋局部白墨 | 品牌感；建議留 NFC 圖示與 QR |
| 尺寸 | 直徑 30–40 mm 或 40×40 mm | 好貼、好感應、可印 QR |
| 包裝 | 3 張一包，含說明卡 | 降低「不知道怎麼用」的退貨 |

**成本假設（未詢價，需打樣確認）**：

- NTAG215 貼紙：約 8–20 元/張。
- 印刷、包裝、說明卡：約 10–30 元/包。
- 物流與金流：約 40–60 元/包。
- 3 張 299 元：扣掉成本後仍有毛利，但量小時物流會吃掉利潤。

## 6. 定價與商品組合

| 方案 | 價格 | 內容 | 目的 |
|---|---:|---|---|
| 體驗包 | 299 元 | 3 張貼紙＋說明卡 | 測試一般飼主 |
| 家庭包 | 399 元 | 5 張貼紙＋家庭權限教學 | 多缸／家庭 |
| Pro 綁定 | 199 元/月或年繳 | Pro＋3 張貼紙 | 把貼紙變成訂閱理由 |
| 爬店／繁殖者套組 | 1,999 元 | 10 張＋店家後台＋售後紀錄 | B2B 首選 |

**建議先賣 B2B 套組與 Pro 綁定，不要先壓大量服飾庫存。**

## 7. 市場與通路

### 最強的第一批客戶

1. **爬店**：賣動物時附贈貼紙，客人回家掃貼紙看售後紀錄；店家可用後台看到客戶與動物。
2. **小型繁殖者**：血統、轉移、照護紀錄；10 張一組，單價高。
3. **特寵獸醫**：飼主就診前用貼紙快速調出用藥與體重；但醫院不會想幫你賣貼紙，適合作為信任背書。
4. **家庭飼主**：小孩刷貼紙記錄，但家長要能限制私人欄位。

### 不建議先做

- 大量 Instagram 廣告賣單張貼紙。
- 沒有 App 留存曲線就補貼貼紙。
- 把 T-shirt 當成主要營收。
- 讓貼紙變成「一定要訂閱才能用」的硬綁定；先讓免費用戶也能綁 1 張，建立習慣。

## 8. 90 天驗證計畫

### 一般飼主（10 戶／30 張）

- 招募 10 個家庭，每戶 3 張貼紙。
- 指標：
  - 綁定完成率 ≥ 80%。
  - 7 天內至少感應 3 次的比例 ≥ 50%。
  - 感應後完成一筆記錄的比例 ≥ 40%。
  - 貼紙遺失／讀不到率 < 10%。
  - 願意用 299 元續購的比例 ≥ 30%。

### 爬店（3 店／各 10 張）

- 店家在售出動物時附贈貼紙。
- 指標：
  - 客人啟用率 ≥ 50%。
  - 店家每週使用後台次數 ≥ 3。
  - 客訴率 < 5%。
  - 店家願意付 1,999 元的比例 ≥ 1/3。

### 技術驗收

- iPhone XS／11／13／15 各一支，實際寫入與感應。
- Android 與 iPhone 7 用 QR code 走同一流程。
- 金屬缸、玻璃缸、塑膠盒各測試 10 次。
- 貼紙遺失後撤銷，舊連結必須失效。
- 未登入、錯帳號、無權限、居民刪除，都要有明確錯誤頁。

## 9. 風險清單

| 風險 | 影響 | 對策 |
|---|---|---|
| 貼紙被複製 | 別人可開你的居民頁 | token 可撤銷、登入才授權、不顯示私密資料 |
| 貼紙遺失 | 無法感應 | App 內撤銷重綁；貼紙上印短碼 |
| Android 無法感應 | 排除一半使用者 | QR code＋短碼 fallback |
| 金屬缸讀不到 | 客訴 | 抗金屬貼紙；說明卡標示 |
| 使用者不知道怎麼綁 | 退貨 | 3 分鐘 onboarding＋測試感應 |
| App 未安裝 | 開網頁 | Universal Link＋App Store 引導 |
| 貼紙變成平台綁定 | 負評 | 匯出、備份、刪除資料的承諾 |
| 周邊分散資源 | 本業不穩 | 先做貼紙與 B2B，服飾延後 |

## 10. 我的建議

**做，但不要做成「周邊商品」。做成「苔間 Pro 的實體入口」與「爬店的售後工具」。**

第一波：

- 3 張 299 元，含 QR code 與短碼。
- Pro 199 方案可加購或年繳內含。
- 先找 3 家爬店、3 位繁殖者、2 位特寵獸醫做種子通路。
- 貼紙不是防偽晶片；隱私靠 token、登入、權限與撤銷，不靠貼紙本身。

如果 90 天內「綁定完成率」與「7 天內重複感應」都達不到，問題不是 NFC 技術，而是這個行為沒有變成照顧流程的一部分。那時應該停的是貼紙，不是 App。

## 11. 仍待確認

- 貼紙供應商與打樣報價。
- iPhone 各機型與金屬缸的實測。
- 店家用後台的最小功能集。
- 貼紙要不要支援「一貼紙多居民」或「一居民多貼紙」。
- 遺失貼紙後，舊 token 的冷卻期與客服流程。
- 是否要把 NFC 寫入做成「購買後由店家代寫」，降低消費者學習成本。
