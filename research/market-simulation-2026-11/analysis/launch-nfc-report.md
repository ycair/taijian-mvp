# 苔間上線＋NFC 周邊商品：MiroFish 市場反應模擬

日期：2026-11-06  
模擬：MiroFish GraphRAG → persona → OASIS（Twitter＋Reddit）  
模型：遠端 Ollama `qwen2.5:14b-instruct`  
圖譜：Zep Cloud `mirofish_4fc677f874214ea4`（86 nodes / 100 edges / 9 chunks）

> 這是一份合成市場模擬，不是真人調查，也不是營收預測。OASIS 的發言是 persona 在模擬社群中的反應；所有數字都應視為假設或質性訊號。

## 1. 摘要

**NFC 貼紙有需求，但需求不是「每個飼主都想要一張」，而是集中在多缸、家庭、爬店與繁殖者。**

模擬中最穩定的訊號是：

1. **單隻寵物的價格敏感使用者會猶豫**：3 張 299 元對「只有一隻守宮」的人來說，張數與價格都不直覺。
2. **Android 使用者感到被排除**：即使有 QR code fallback，還是會覺得苔間是 iPhone 俱樂部。
3. **隱私與遺失是最大阻力**：使用者會擔心貼紙被撿到、被重寫、或讓別人看到紀錄。
4. **家庭與店家是最強的使用情境**：小孩刷貼紙記錄、爬店賣動物附售後貼紙，比「一般飼主自己買」更合理。
5. **周邊商品不是主營收**：貼紙、缸邊標籤、照護卡是功能型周邊；托特包、徽章、T-shirt 應該是品牌，不是第一年的重點。
6. **199 元仍是 App 的價格錨點**：15 位 panel 中 10 位選 199、3 位選 99、2 位選免費、0 位選 399；NFC 應該是 Pro 的加值或 B2B 套組，不應該變成另一個獨立訂閱。

**建議：先把 NFC 做成「Pro 的實體入口」與「爬店的售後工具」，不要先做大量服飾周邊。**

結構化 panel 的結果：App 平均興趣 3.67/5、試用機率 75.3%、付費機率 31.3%；NFC 平均興趣 2.53/5、購買機率 27.3%，只有 5/15 認為 3 張 299 元可以接受；周邊平均興趣 2.47/5。NFC 是小眾加購，不是全民功能。

## 2. 模擬方法與限制

### 做了什麼

- 使用 15 個台灣爬蟲／特寵 persona，加上圖譜抽取出的角色，共 20 個 profiles。
- GraphRAG 建圖：9 chunks、86 nodes、100 edges。
- OASIS 平行跑 Twitter 與 Reddit，8 輪；Twitter 18 則貼文、Reddit 8 則貼文＋8 則留言。
- 因為第一次 Reddit 留言太少，另跑一次 12 輪、提高活動度的 Reddit 重跑；在時間限制下取得 6 則貼文＋13 則留言（部分留言離題，見限制）。
- 另外用同一批 persona 做結構化 panel，問 App 付費、NFC 購買、周邊興趣與最大疑慮。

### 不能拿它做什麼

- 不能推論母體比例。20 個合成 persona 不是台灣爬蟲市場的隨機樣本。
- 不能把 OASIS 的留言當成真人引用。它是模擬預測，不是訪談逐字稿。
- Qwen 14B 會離題：第二次 Reddit run 有留言把 NFC 貼紙理解成門禁卡、支付或室友權限，這些已排除在主要證據之外。
- 回合數與留言數仍偏少；本報告的價值在於「反對理由與使用情境」，不是「支持率」。

## 3. 主要發現

### 3.1 NFC 貼紙：多缸、家庭、店家才是真需求

單隻寵物使用者最常見的反應不是「很酷，我要買」，而是「我只有一隻，為什麼要買三張？」

> 「这个新的NFC贴纸功能听起来很有意思，但是我只有一只宠物，还需要另外支付费用，所以现在还不确定是否要购买。感觉有时候这些高级功能就是有点贵。」
> — 小安，Reddit 留言（R1-C3）

同樣的價格敏感也出現在免費版使用者身上：

> 「雖然我對這些附加工具沒那麼感興趣，但我很重視照片的保存和質量。有沒有辦法在免費版的基礎上，也能達到同樣的效果呢？」
> — 阿宏，Reddit 留言（R1-C2）

相反地，禮物購買者對 299 元的接受度較高：

> 「我觉得NFC贴纸很有意思……关于价格，我觉得3张贴纸299元还可以接受。」
> — 小美，Reddit 留言（R2-C11）

**解讀**：299 元不是絕對太貴，而是「對只有一隻寵物的人來說，價值不對稱」。產品說法要從「3 張貼紙」改成「3 個照顧入口」：缸、飼料盒、外出盒；或直接賣 1 張入門包。

### 3.2 Android 不是小問題，是 adoption gate

Android 使用者的反應很直接：

> 「我作为Android用户，确实觉得NFC功能支持有限是个遗憾……我们可以通过更多的方式，比如社交媒体平台讨论，让他们知道我们需要一个跨平台的NFC解决方案。」
> — Kevin，Reddit 留言（R1-C6）

另一位 Android 使用者則說：

> 「虽然我对NFC的限制感到失望，但这也激发了我对安卓设备和移动应用的进一步探索。我认为，虽然199元的Pro版本可能不包括NFC，但它仍然是一款值得尝试的产品。」
> — 小美的男友，Reddit 留言（R1-C4）

**解讀**：QR code fallback 只能「讓 Android 也能用」，不能「讓 Android 覺得被重視」。貼紙上必須同時印 NFC 與 QR，文案要寫「iPhone 感應／Android 掃碼」，而不是把 QR 藏在說明卡裡。

### 3.3 隱私與遺失，是購買前的最後一道門檻

> 「NFC标签确实可以绑定多户主，但是安全性如何保障呢？如果一个房间有3个室友，怎么确保信息安全？确实需要谨慎考虑标签的使用方式。」
> — 林醫師，Reddit 留言（R1-C7）

> 「我发现这个讨论中有一个重要的问题被忽略了——这样的行为是否侵犯了用户的隐私权？虽然NFC技术可以带来便利，但它也可能被商家利用来获取用户的个人信息。」
> — 小美的男友，Reddit 留言（R2-C7）

**解讀**：使用者不只怕「貼紙掉了」，也怕「貼紙被別人撿到」與「商家拿到資料」。MVP 必須把「登入才授權、token 可撤銷、不把居民 ID 寫進 URL」說清楚，並且在包裝上直接寫「別人撿到貼紙也看不到你的紀錄」。

### 3.4 家庭與小孩，是 NFC 最自然的場景

> 「我很喜欢NFC贴纸这个创意，这可以帮助孩子们在学习如何照顾乌龟的同时也能享受到技术的乐趣。不过我们也需要确保我们的孩子不会被技术过度包围……」
> — 雅婷，Reddit 留言（R2-C1）

**解讀**：雅婷的顧慮不是「NFC 很難」，而是「小孩会不会亂刷、看到不該看的」。家庭權限（孩子只能記錄、不能看醫療私密欄位）比 NFC 本身更重要。

### 3.5 爬店是最強 B2B 通路，但需要售後後台

> 「小林的宠物店最近开始推行NFC贴纸和苔間App，为顾客提供便捷的照护记录获取方式。这不仅能帮助顾客更好地管理宠物的健康记录，同时也能提升店铺的专业形象。」
> — 小林，Reddit 留言（R2-C13）

陳老闆則把 NFC 類比為養殖業的自動化工具：

> 「爬蟲養殖業界也有類似的高科技應用，像是自動餵食系統和溫度濕度控制器，可以改善養殖環境……這與NFC技術應用相似，都是為了便利和效率而設。」
> — 陳老闆，Reddit 留言（R2-C9）

**解讀**：店家不是想賣貼紙，而是想用貼紙綁定售後關係。B2B 套組應該包含「客人掃碼看照護紀錄」與「店家後台看客戶／動物」，不是只給 10 張貼紙。

### 3.6 周邊商品：功能型可以，品牌型先緩

模擬中對托特包、徽章、T-shirt 幾乎沒有正面討論；討論都集中在貼紙、標籤與照護卡。這不代表周邊一定賣不掉，而是**它沒有出現在使用者的購買理由裡**。

**解讀**：第一波只做「會用到的周邊」：NFC 貼紙、缸邊標籤、照護記錄卡、繁殖／售後套組。服飾與盲盒等品牌周邊，等 App 留存曲線穩定後再說。

### 3.7 結構化 panel：199 仍是主錨點，NFC 是小眾加購

| 指標 | 結果 |
|---|---|
| App 平均興趣 | 3.67 / 5 |
| 試用機率 | 75.3% |
| 付費機率 | 31.3% |
| 偏好方案 | 199 × 10、99 × 3、免費 × 2、399 × 0 |
| NFC 平均興趣 | 2.53 / 5 |
| NFC 購買機率 | 27.3% |
| 3 張 299 元可接受 | 5 / 15 |
| 周邊平均興趣 | 2.47 / 5 |

願意接受 299 元三張貼紙的，主要是多缸、繁殖者、店家與 DIY 使用者：Eric、陳老闆、老周、阿德、小林。單隻寵物、價格敏感與 Android 使用者多數說不。

> 「數據的準確性和透明度是我們的首要考量，苔間App在這方面有潛力。」
> — 老周（panel）

> 「苔間App有潛力，但開放性不足，希望未來能更自由些。」
> — 阿德（panel）

> 「禮盒好漂亮，但希望有更多使用說明」
> — 小美（panel，禮物購買者）

> 「詳細的健康記錄是治療成功的重要關鍵，但技術手段需小心使用。」
> — 林醫師（panel）

**解讀**：panel 把「NFC 不是全民需求」講得更清楚。199 元 App 訂閱有 10/15 支持；NFC 貼紙只有 5/15 接受 299 元。這支持「NFC 是 Pro 加購／B2B 套組」而不是獨立主產品。

## 4. NFC 技術與產品可行性

### 4.1 iPhone 能力邊界

- iPhone XS／XS Max／XR／SE 第 2 代以後：支援背景讀取 NDEF；螢幕亮、開機後解鎖過一次即可；Apple Pay、相機、飛航模式會暫停。
- iPhone 7／8／X：可讀 NFC，但需要 App 或控制中心的手動讀取。
- 寫入 NDEF：iOS 13 以後可用 Core NFC；App 需要 `NFCReaderUsageDescription`。
- NDEF URL 可走 Universal Link 開 App；未安裝 App 時開網頁 fallback。

### 4.2 建議流程

**空白貼紙綁定**

1. App →「居民」→「NFC 貼紙」→「綁定新貼紙」。
2. 靠近貼紙，App 寫入 `https://taijian.ycair.space/n/<token>`。
3. 選擇居民、貼紙名稱、權限。
4. 立即試刷一次，成功才完成。

**已設定貼紙感應**

1. iPhone 靠近 → 系統通知 → 點擊開 App。
2. App 用 token 向伺服器解析。
3. 已登入且有權限 → 該居民快速記錄頁。
4. 未登入 → 登入後回到同一頁。
5. 無權限／token 撤銷 → 明確錯誤與重綁引導。

### 4.3 安全設計

- URL 只放隨機 token，不放 `resident_id`、Email、病歷。
- 資料庫只存 token hash；token 至少 128-bit。
- 感應不是授權；仍要登入與家庭權限檢查。
- 貼紙遺失可撤銷；舊 token 立即失效。
- 記錄感應事件（誰、何時、哪個 tag）用於異常偵測。
- NTAG215／216 的 NDEF 可被複製；若要防拷貝，升級 NTAG 424 DNA 的 SUN/SDM，但這是第二階段。

### 4.4 成本與定價假設

| 項目 | 假設 |
|---|---|
| NTAG215 貼紙 | 8–20 元/張 |
| 印刷、包裝、說明卡 | 10–30 元/包 |
| 物流與金流 | 40–60 元/包 |
| 3 張售價 | 299 元 |
| 5 張售價 | 399 元 |
| B2B 10 張＋後台 | 1,999 元 |

這些是待打樣與詢價的假設，不是已驗證成本。

## 5. 商轉建議

### 5.1 產品組合

1. **Free**：基本記錄＋1 張貼紙綁定（降低嘗試門檻）。
2. **Pro 199**：匯出、家庭權限、進階提醒、公開頁控制；年繳含 3 張貼紙。
3. **NFC 體驗包 299／3 張**：給多缸、家庭、禮物購買者。
4. **B2B 1,999／10 張＋店家後台**：爬店、繁殖者、特寵獸醫。
5. **功能型周邊**：缸邊標籤、照護卡；服飾與盲盒延後。

### 5.2 通路順序

1. 3 家爬店（各 10 張）＋3 位繁殖者（各 10 張）。
2. 2 位特寵獸醫（不賣貼紙，做信任背書與就診情境）。
3. 2 位內容創作者（開箱與教學，不買大量廣告）。
4. 寵物展（只做名單與示範，不當留存證據）。

### 5.3 90 天 gate

| Gate | 目標 | 未過就做什麼 |
|---|---|---|
| 綁定 | 10 戶／30 張，綁定完成率 ≥ 80% | 修 onboarding 與說明卡 |
| 使用 | 7 天內感應 ≥ 3 次的家庭 ≥ 50% | 檢查貼紙位置與提醒設計 |
| 記錄 | 感應後完成一筆記錄 ≥ 40% | 簡化快速記錄頁 |
| 付費 | 299 元續購或 Pro 加購 ≥ 30% | 改價格或改組合 |
| B2B | 3 店中至少 1 店願意付 1,999 元 | 補店家後台與客訴流程 |
| 相容 | Android／舊 iPhone 用 QR 完成率 ≥ 60% | 調整 QR 位置與文案 |

**Kill criteria**：如果 10 戶中少於 3 戶在 4 週後仍每週感應，或 3 店中沒有 1 店願意付費，先停貼紙，不要加大周邊庫存。

## 6. 我還不確定的地方

- 貼紙供應商與打樣報價。
- 金屬缸、玻璃缸、塑膠盒的實際感應率。
- 店家用後台的最小功能集。
- 「一貼紙多居民」或「一居民多貼紙」的資料模型。
- 遺失貼紙的客服與冷卻期。
- Android 使用者是否願意為了 QR 而買貼紙。
